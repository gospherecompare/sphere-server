## Common Issues & Solutions

### Issue: Form Won't Submit
**Solution:**
- Ensure ALL required fields are filled
- Check that variant has both screen_size AND base_price
- Verify each store has both name AND URL
- Check for any validation error messages in red

### Issue: Store Prices Show as $0 or NULL
**Solution:**
- Re-enter prices (should be numeric: 134990, not ₹134,990)
- Ensure price field is not left empty
- Check database: may need to clear cache

### Issue: Variant Not Appearing
**Solution:**
- Ensure variant_key is unique per product
- Check screen_size is not empty
- Verify base_price is a valid number
- Try refreshing page

### Issue: Edit Form Showing Old Data
**Solution:**
- Clear browser cache (Ctrl+Shift+Delete)
- Reload page (F5)
- Close and reopen browser
- Check server is running (npm start)

## After Submission: What to Check

### In Database
```sql
-- Product exists
SELECT id, product_name FROM products WHERE product_name LIKE 'Sony BRAVIA%';

-- Variants created (should see 2)
SELECT id, screen_size, base_price FROM product_variants 
WHERE product_id = (SELECT id FROM products WHERE product_name LIKE 'Sony BRAVIA%');

-- Store prices (should see 5)
SELECT store_name, price, url FROM variant_store_prices 
WHERE variant_id IN (
  SELECT id FROM product_variants 
  WHERE product_id = (SELECT id FROM products WHERE product_name LIKE 'Sony BRAVIA%')
)
ORDER BY variant_id, store_name;
```

## Tips for Faster Entry

1. **Copy-Paste URLs:**
   - Have URLs in notepad
   - Paste directly into URL fields

2. **Use Tab to Navigate:**
   - Faster than clicking each field
   - Reduce mouse usage

3. **Pre-fill Store Info:**
   - All 3 stores for 55" can be pre-formatted
   - All 2 stores for 65" can be pre-formatted
   - Copy between variants to save time

4. **Batch Store Entry:**
   - Add all 55" stores first, then 65" stores
   - More efficient workflow

5. **Verify Before Saving:**
   - Scroll to top after adding variants
   - Review all fields one more time
   - Check for any red error messages
